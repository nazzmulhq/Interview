# Full-Stack & System Design Bengali Interview Portal

A comprehensive portal for interview preparation, featuring 1,400+ questions and answers in Bengali with real-time text-to-speech support.

## Features
- 1,400+ questions on JavaScript, React, Next.js, Node.js, Express, NestJS, Python, Django, FastAPI, Database, MongoDB, System Design, NGINX, Microservices, RabbitMQ, Kafka, gRPC, Elasticsearch, Redis, AWS, Kubernetes, DSA, etc.
- Text-to-speech functionality to read Bengali Q&A aloud using Google TTS.
- Category filtering and search.
- Topic-wise sequential audio playback.
