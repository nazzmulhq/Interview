# Full-Stack & System Design Bengali Interview Portal

A comprehensive portal for interview preparation, featuring 600+ questions and answers in Bengali with real-time text-to-speech support.

## Features
- Over 600+ questions on JavaScript, Node.js, Express, NestJS, Database, MongoDB, System Design, NGINX, Microservices, RabbitMQ, Kafka, gRPC, Elasticsearch, Redis, etc.
- Text-to-speech functionality to read Bengali Q&A aloud using Google TTS.
- Category filtering and search.
- Topic-wise sequential audio playback.
